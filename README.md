# 🌱 EcoScore AI – Sustainability Advisor

> **A Machine Learning-powered sustainability assessment system that predicts a product's lifecycle carbon footprint and generates an EcoScore to promote environmentally conscious decision-making.**

---

## 📖 Overview

EcoScore AI is an AI-powered sustainability assessment application that analyzes a product's environmental impact using Machine Learning. It predicts the **lifecycle carbon footprint** of a product and generates an **EcoScore** based on various sustainability metrics.

The application also provides interactive visualizations and comparative analysis to help users make informed and eco-friendly decisions.

---

## ✨ Features

- 🌍 Predict product lifecycle carbon footprint
- 📊 Generate an EcoScore based on sustainability metrics
- 📈 Interactive analytics dashboard with visualizations
- 🔄 Compare sustainability performance of multiple products
- 🤖 Machine Learning-powered predictions
- 💻 User-friendly Streamlit interface

## 🚀 Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/shreyaberlikar/EcoScore-AI-Sustainability-Advisor.git
```

### 2️⃣ Navigate to the project directory

```bash
cd EcoScore-AI-Sustainability-Advisor
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the application

```bash
streamlit run app.py
```
