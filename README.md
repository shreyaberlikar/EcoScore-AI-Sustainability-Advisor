# 🌱 EcoScore AI – Sustainability Advisor

## Overview

EcoScore AI is a Machine Learning-based sustainability assessment system that predicts a product's lifecycle carbon footprint and generates an EcoScore to help users evaluate its environmental impact. The application combines AI, data analytics, and interactive visualization to promote informed and sustainable decision-making.

## Features

* 🌍 Predicts product lifecycle carbon footprint
* 📊 Generates an EcoScore based on sustainability metrics
* 📈 Interactive analytics dashboard with visualizations
* 🔄 Compare sustainability performance of multiple products
* 🤖 Machine Learning-powered predictions
* 💻 User-friendly Streamlit interface

## Tech Stack

* **Programming Language:** Python

## Installation

Clone the repository:

```bash
git clone https://github.com/shreyaberlikar/EcoScore-AI-Sustainability-Advisor.git
```

Navigate to the project folder:

```bash
cd EcoScore-AI-Sustainability-Advisor
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
